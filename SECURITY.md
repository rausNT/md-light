# Security policy

## Supported versions

Security fixes are provided for the latest published version of MdLight.

| Version | Supported |
|:--------|:---------:|
| 0.3.x   | Yes       |
| 0.2.x   | Yes       |
| < 0.2   | No        |

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue. Use
[GitHub private vulnerability reporting](https://github.com/rausNT/md-light/security/advisories/new)
and include:

- the affected version;
- reproduction steps or a proof of concept;
- the expected and observed behavior;
- any known impact or suggested mitigation.

The maintainer will acknowledge a report within seven days, investigate it,
and coordinate a fix and disclosure when the report is confirmed. Good-faith
research that avoids privacy violations, service disruption, and data damage
is welcome.
