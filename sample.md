# MdLight

> A lightweight Markdown viewer for Windows.

Open this file in **MdLight** to quickly check the rendering.

## Supported content

- regular lists;
- [x] completed tasks;
- [ ] incomplete tasks;
- *italic*, **bold**, ~~strikethrough~~, and `code`;
- [links](https://github.com/rausNT/md-light).

| Feature    | Status |
|:-----------|:------:|
| Headings   | Ready  |
| Tables     | Ready  |
| Dark theme | Ready  |
